# Figure and video sources

One row per file in `figures/` and `videos/`: what it shows, the script that made it, the data it read,
and, for anything taken from another paper, the citation key and license. Every file is regenerated by
`scripts/make_all_figures.sh` (shared style: `scripts/style.py`; run-data helpers: `scripts/runs.py`, which
reuses the parser of `scripts/aggregate_results.py`). Paths below are relative to `comfree_tdmpc/outputs/`
unless they start with `blogpost/`, `sim2sim/` or `tdmpc-square-pearl/`. Each figure exists as `.svg` (embed
this) and `.png` (200 dpi); the rows cover both. Backgrounds are transparent and the colours are chosen to read
in both the light and the dark theme.
